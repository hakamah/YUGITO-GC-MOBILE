# YUGITO 2.0 — GODOT PREMIUM PROTOTYPE 03

Base : Prototype 02.1 TYPEFIX validé visuellement.

## Passe visuelle 03

- Nom + PV déplacés dans un vrai header externe au-dessus de chaque carte.
- Les illustrations ne sont plus recouvertes par le header ; Sasuke et les portraits serrés respirent davantage.
- Deux rangées repositionnées pour intégrer ces headers sans écraser le centre du terrain.
- Header premium : ombre, accent élémentaire, bord dynamique, capsule PV.
- Verre retravaillé : texture historique plus discrète + shader GPU multi-reflets, lumière locale au curseur et liseré de bord.
- Hover plus physique : élévation progressive, micro-rotation, micro-perspective et ombre dynamique, sans bond.
- Sélection +4 % réellement progressive ; une seule carte sélectionnée à la fois.
- Le panneau PLAN DU TOUR reflète maintenant la carte réellement sélectionnée (nom, PV, élément, TAI/NIN/GEN).
- Ambiance centrale renforcée discrètement : anneaux faibles, filaments d'énergie et davantage de motes chakra.
- Aucun gameplay de combat définitif raccordé à ce stade.

## Base suivante

Ce prototype reste la branche visuelle Godot. Le vrai gameplay YUGITO sera raccordé après validation du rendu/ergonomie.
