# P40 — CHECKLIST RUNTIME / MOBILE

Cette checklist ne doit PAS être cochée automatiquement : elle exige le runtime Godot et/ou un vrai appareil.

- [ ] 60 Hz : 3 combats complets, aucune accélération/ralentissement des cartes.
- [ ] 120 Hz : même durée visuelle/animations qu'à 60 Hz.
- [ ] 144 Hz : même durée visuelle/animations qu'à 60 Hz.
- [ ] Android : Shifumi, Draft, choix des 3, combat, remplacement, retour menu.
- [ ] A1 + A2 spéciales sur plusieurs tours.
- [ ] Shikamaru A1 et A2 : bandeau 3T → 2T → 1T sans clignotement.
- [ ] Kisame/Jashin/Ombres : marqueurs locaux, aucune grande ligne.
- [ ] Ino : corps source blanc/inciblable, corps possédé ciblable, restitution exacte.
- [ ] Temari expulse une cible avec états persistants et ceux-ci reprennent au retour.
- [ ] Tobi : bombes ×1…×5, 320 chacune, A1/A2 prediction.
- [ ] Zetsu + Tobi + Switch A2.
- [ ] Ao tue un lanceur avant sa spéciale.
- [ ] 3 K.O. successifs et remplacements FIFO.
- [ ] Résolutions 16:9, 16:10, ultrawide + Android : aucune UI coupée.
- [ ] Modales : aucun clic ne passe derrière.
